# YUNO / MUSIC & WORKS

A dependency-free bilingual static portfolio for GitHub Pages. Its public-source catalog is rendered from JSON in the browser; no build step is required.

Original works are curated from YUNO's official YouTube playlist and grouped by detailed instrumentation. `npm run refresh:originals` rebuilds the original-work portion of `data/works.json` from the reviewed catalog stored in the script while preserving arrangements.

Run `npm test` (Node 18+; no installation required) to validate data shape, dates, routes, commentary references and local links.
